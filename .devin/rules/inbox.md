# Inbox

Transient quick-capture landing zone. Zero friction in, process regularly, goal is empty. For philosophical grounding, see `references/ethos.md#inbox`.

## Do Not
- Leave items indefinitely — this is a transit zone, not a permanent home
- Create structured notes here — if you know where something belongs, put it there directly
- Use as a reading list — articles and videos should move to `references/` once triaged

## Do
- Use for quick captures when you don't have time to file properly
- Process regularly — ideally during the GTD Weekly Review or via `/process-inbox`
- Move items to their correct folder once processed; don't let them accumulate
- Treat `Inbox.md` as an index page, not a dumping ground for content

## Co-located Views
- `Inbox.base` — inbox triage queue. Lives in `inbox/`.

## Processing Workflow
1. For each item, decide: *What is this? Where does it belong?*
2. Move to the appropriate folder (`references/`, `garden/`, `projects/`, `areas/`, or `zettelkasten/`) and apply correct template/frontmatter
3. If not worth keeping, delete it
4. Inbox should be empty (or near-empty) after processing
