# Objective

Set up a functional home gym in the garage that supports strength training and basic cardio, within a $2,000 budget.

# Brainstorm

- Need a power rack, barbell, and plates as the foundation
- Rubber flooring to protect the garage floor and reduce noise
- Pull-up bar (many power racks include one)
- Adjustable dumbbells for accessory work
- Maybe a rower or assault bike for cardio — but these are expensive
- Climate control is an issue — garage gets hot in summer
- Need to measure the garage to make sure a full rack fits with enough clearance
- Consider buying used equipment — significant savings on plates and bars

# Metrics

- All equipment purchased and assembled
- Garage space cleared and flooring installed
- Can perform all major compound lifts safely at home
- Total spend under $2,000
