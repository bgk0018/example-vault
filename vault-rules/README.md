# Vault Rules (Hermes Mirror)

Semantic mirror of `.windsurf/rules/` and `.windsurf/workflows/`, normalized for Hermes consumption.

## How to consume

- Read folder-specific rules before operating in that folder (e.g., `global-conventions.md`, then `zettelkasten.md` if working in zettelkasten).
- Use `workflows/*.md` as step-by-step facilitation scripts.
- Use `references/*.md` for property and linking conventions.
- Use `skills/*.md` for tooling semantics (CLI/obsidian/bases/canvas).

## Canonical source

This tree is generated from `.windsurf/...` and should not be edited directly. Edits should happen in `.windsurf/`, then `scripts/sync-vault-rules.sh` is rerun.
